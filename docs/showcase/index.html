SpiritOps

Weekly wholesale purchase forecasts with automatic retraining, model evaluation and rollback.

Static showcase · Recorded on a local CPU-only deployment

Model lifecycle

The dashboard shows a historical replay over two Iowa stores. The controller queued a challenger under a deliberately sensitive alert threshold. Its holdout WAPE improved from 147.76% to 97.79%. A subsequent baseline candidate failed the release gate.

Single-host architecture

Iowa invoices → DuckDB validation → weekly Parquet → shared features
Worker → LightGBM → MLflow → release gates → deployment manifest
FastAPI → predictions + matured labels → monitoring → worker queue

Measured service behavior

100 serial requests reached 49.9 ms P95. Eight concurrent clients reached 38.2 requests per second at 333.0 ms P95. All 91 probes during training and activation returned valid forecasts. Removing the active artifact triggered recovery in 5.30 seconds.
